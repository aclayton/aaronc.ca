Prototype · where the content lives

A private vault, with one shared directory inside it

Privacy here is a property of where the content lives, not a promise about who reads it. The vault is per person and private; one directory inside it is its own git repository, and that is the only surface a teammate ever sees. Agent updates reach it through a pull request.

That is the shared surface — a set of knowledge and agent repos, and the only part of the vault anyone else sees. It carries a personal space inside it, which is never pushed.

GitHub is the only transport. The shared directory is a repository: pulled for updates, changed through a pull request. Nothing else syncs this tree, so there is no second transport to collide with it.

Nothing is overwritten. A destination that already exists is never replaced, and a managed target that has been modified fails the install closed.
Nobody writes the trunk. An agent update arrives as a pull request — for every developer, not only the ones who already have write access.
Pull is fast-forward only — divergence is reported, never auto-merged. Still a prototype: no git transport yet.
